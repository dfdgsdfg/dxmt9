## Encoder / state debug

The durable encoding providers are Stage 1/Stage 2/Stage 2b/resource-array
binding and portable FFP execution; tile-auto is correctness-blocked; see
`specs/backend/render-provider/spec.md`. Rollback flags remain supported, while
`force`, `measure`, `probe`, state suppression, and correctness-invalid mutation
flags are diagnostic. The production-shaped candidates called out explicitly
below remain default off and are not provider compatibility promises.
