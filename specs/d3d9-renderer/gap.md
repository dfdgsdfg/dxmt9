## Modern Renderer Path

| Area | Status | Current evidence | Missing work |
|---|---|---|---|

| L1 device-free graph (`R-BACK-32.*`–`R-BACK-34.*`, `R-BACK-39.7`, `R-BACK-41.2`) | implemented | `fg_dag`, `fg_builder`, lifetime/passcoalesce/memoryless-classifier/dce/reorder/loadstore, `fg_linearizer`, and JSON/dot/mermaid pre/post export are covered by native specs. | Production `passcoalesce` (`R-BACK-34.*`, `R-BACK-38.*`, `R-BACK-40.1`) | partial / default | The default `framegraph + progressive + passcoalesce` lane retains every source command in the DAG, validates a complete duplicate-free optimized permutation, and replays it through the canonical `encodeChunk` path. Store proof follows that replay order and keeps invalid evidence conservative; explicit traditional, strict, and empty-feature rollbacks remain. Alias-aware GT2 frame279 preserves the `R32F write → sample → R32F write` chain while reducing `18 -> 16` render encoders. Post-fix GT1/GT2/GT3 runs completed with zero GPU/pipeline failures and reduced render-pass/present counts; exact GT3 captures across 1:06–1:08 do not reproduce the quadrant glitch. An env-clean default SFIV run reaches a valid rendered scene; a separate perf run encodes `7,320` Presents and `1,674,130` draws with zero chunk rejects, GPU command-buffer errors, pipeline-build failures, or missing-pipeline draws. Earlier pre-fix `18 -> 15` evidence is invalid because it moved a consumer before its producer. | Cross-source serial `passcoalesce` (`R-BACK-2.43`) | implemented behind default-off CPU-ready Tape gate / GT2 locality gate failed | A bounded combined graph preserves exact `(source, commandIndex)` attribution, complete RAW/WAR/WAW dependencies, DrawRun-only cross-source movement, natural FIFO completion, and all-or-nothing preflight. Production native tests cover reordered Legacy/Arena fragments, the eight-source window bound, and a natural Present tail in one session/command buffer. A no-gputrace GT2 run attempted 1,527 windows: all 996 eligible windows merged the active-pass seed, but every linearization remained natural and no production window reordered. The run stayed error-free at `4.038` command buffers/Present but retained `17.596` passes/Present versus the earlier tape-off `15.77` envelope; the compared provider binaries are not identical builds. | Keep default off and do not weaken alias or dependency rules to force activation. Correlate natural seed merges with the first matching pass distance before deciding whether the dominant gap is snapshot reach or dependency-preserving logical-pass segmentation. If intervening dependency-preserved windows dominate, track the latter in the encode-scheduling Metal 4 and logical-action gaps. |
| Production bounded DCE (`R-BACK-32.10`) | partial / opt-in | Explicit `dce` encodes a proof-independent prefix, samples only an already-ready FIFO successor, canonicalizes both independent DAGs, accepts only first-access full Clears, validates the prefix plus ordered canonical suffix, preserves original completion sources, and immediately completes without proof when no successor is ready. Native builder/optimizer/linearizer/queue-policy specs and `DceChunkLookahead.tla` cover the mechanism. The valid passcoalesce-prefix forced-wait A/B dropped `389` passes and `56,283` commands but regressed `9.157 -> 6.902 FPS`; the accepted no-wait bootstrap run recovered `8.938 FPS`, selected only `1/536` successors, and omitted only `30` commands. No GPU/pipeline error or visible corruption was observed. See `docs/perfomance/hidden-backend-storage/hidden-backend-storage-shape.42.md`. | Keep opt-in. Run GT1/GT3/SFIV guards and deterministic device-backed pixel parity only if broader enablement is reconsidered. A new Xcode capture is justified only on a workload that supplies material already-ready successor volume; GT2 currently does not. |
| General bounded ready-prefix proof (`R-BACK-32.11`) | not started | The one-successor implementation already establishes independent per-chunk DAG ownership, no-wait selection, and conservative fail-open behavior. | Other production L1 features | not started | Analysis-only DAG passes can classify `memoryless` and `reorder`; they do not change Metal emission. | Wire persistent memoryless observation and `TransientAttachmentPool`, semantic-relaxation gates, whole-pass fallback, dry-run divergence, and device-side parity evidence. |
| L2/L3 mesh, bindless, object scheduling, and GPU-driven path (`R-BACK-35.*`–`R-BACK-37.*`, `R-BACK-41.3`–`R-BACK-41.4`) | not started | Requirements and phasing are documented. | Implement route/emitter, cache namespace, bindless heap, mesh dispatch, object scheduling, ICB path, counters, and reduced-counter parity gates. |
| Classic-draw ICB materialization lane (`R-BACK-36.5`) | not started — staged behind explicit prerequisites | Requirement and design sketch landed 2026-08-05 (spec.md §10.4): per-pass POD draw tape from existing slot SoA + bindless addresses, CPU-prefilled ICB with statically pre-encoded dynamic-state range sandwiches inside one encoder, non-expressible draws fall back to direct encoding. Motivated by the encode-thread wall (~38% GT2) as a post-partitioning alternative; the tape-integration experiment's CB +127% pass-fragmentation failure shape is the named anti-goal. No production precedent exists in comparable translation layers — treat as exploratory. | Prerequisite gate (a): encoder-dynamic-state transition histogram probe on GT2 + one GPU-bound workload to establish ICB-expressible draw share (70–90% hypothesis, unmeasured) and range counts. Then: CPU-prefill lane, deterministic ICB-content verification seam, R-BACK-2.50-order promotion evidence; GPU-compute fill only after CPU-prefill promotion. |

The production command-tape lane is intentionally narrower than the staged
`executeLinearization` design. It does not bypass canonical batching, dirty-rebind,
capture, presenter, or completion behavior, and it falls back to source order
when a session, injected command buffer, Clear/helper merge boundary, or replay
permutation cannot be proven safe.

The intentionally independent `provider_replay.v2` output separates provenance segment count from queue-completed segment evidence: derived rows report zero completed segments and no final queue settlement, while capture/provider-replay rows report those fields only after the authenticated tail fence. Malformed controls, unbound/truncated/swapped settlement rows, and v1 fail closed before effects. | Broaden device-backed multi-event GT2 evidence and projection-consumer integration; keep the sidecar settlement table bounded and consumed, and do not revive `identity.v1`. |
