no `src/d3d9`/`src/winemetal` change, TLA queue-ordering unchanged, both perf-counter audits green): `fg_dag` structures, `fg_builder` (ChunkSlot→DAG), the six optimizer passes + orchestrator (lifetime/passcoalesce/memoryless-classifier/dce/reorder/loadstore, default order-preserving), `fg_linearizer` (device-free plan + device-gated executor), `fg_debug_export` (R-BACK-39.7: JSON/dot/mermaid, `DXMT9_RENDERER_DUMP_DAG[_FORMATS]`), `framegraph_*` counters (L1 subset), and `FrameGraphBackend` wiring that builds+optimizes+exports the DAG as a pure observation side-channel while encode stays byte-identical. **Deferrals:** the device-gated encode-rewrite — driving production Metal encode via `fg_linearizer::executeLinearization` so passcoalesce/memoryless actually change output (+ memoryless `TransientAttachmentPool` alias, byte-exact passcoalesce parity proof, dry-run divergence engine) — is the documented L1→on-device frontier; `framegraph_icb_*` / `virtual_attachment_misclassification` counters and L2/L3 (mesh/bindless/GPU-driven) remain unimplemented; an in-repo CI runner surface for R-BACK-39.4 still does not exist (the merge-blocking script does). **Anti-dependency (WAR/WAW) edge gap — CLOSED (R-BACK-32.9):** the builder edge model is no longer RAW-only. `fg_builder::addDependencyEdges` now emits a complete hazard model — RAW (write→later read), WAR (read→later write), WAW (write→later write), Clear-as-write, ReadWrite-as-both, all earlier→later with self/dup suppression — so the edge-consuming optimizer passes are correctness-safe: `reorder` (Kahn topo over `graph.edges`) and `passcoalesce` (`reaches()` over `graph.edges`) can no longer move a write before a prior read or swap two writes. design §4.2 rewritten and R-BACK-32.9 makes the contract normative (and forbids enabling those passes on a RAW-only builder). Tested: WAW re-entry edge (the 3DMark05 clear-then-write A→B→A shape, previously `edges=0`), WAR read-then-write edge, reorder-respects-anti-dep (load-bearing), passcoalesce-blocked-by-anti-dep. `reorder`/`passcoalesce` remain feature-gated off in `strict` pending the device-gated encode-rewrite + per-profile enable decision, but the edge-correctness prerequisite is met. The `dce` cross-chunk-safety AND-vs-OR correctness fix from final review is applied. Phasing: L0 ✅ → L1 ✅ (observation/export + optimizer; encode-rewrite device-gated) → L2 (mesh + bindless) → L3 (GPU-driven), `requirements.md` §12 / spec.md §14. Motivation: `docs/perfomance/overview-3dmark05-gt1.md` (P0 hidden vertex-stage / TVB write bucket unreachable from the 1:1 path). |
