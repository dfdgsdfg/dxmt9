# Tests DoD Inventory

This inventory tracks test-related ownership, evidence, remaining gaps, and the
next acceptance criterion. It is docs-only and reflects the current working tree
state described by `specs/tests/requirements.md`, `specs/tests/design.md`,
`specs/gap.md`, `tests/meson.build`, and the test manifests.

Status legend: `done` means the current gap tracker lists the area as satisfied;
`partial` means useful evidence exists but required acceptance remains open;
`open` means the specified test area is not implemented yet.

## Immediate Acceptance Focus

1. Keep docs, manifests, and Meson registrations consistent: `dxmt9-manifest-check`
   and `dxmt9-d3d9-conformance-manifest-check` are the minimum docs/test inventory
   gates.
2. Extend the runtime probe layer beyond texture / VS color / viewport /
   color-write probes to the remaining GPU-visible cases.
3. Keep PE scaffold status separate from runtime evidence until the newly
   exposed app-local failures are either fixed or intentionally classified.
4. Promote PE conformance from inventory to evidence by running scaffolded cases
   under Wine app-local and builtin lanes, then updating manifest statuses from
   `scaffolded` to `passing`, `failing`, or justified `skipped`.
