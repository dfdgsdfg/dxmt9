# Render Provider Policy Gap

| Area | Status | Current evidence | Missing work |
|---|---|---|---|
| Policy classification (`R-BACK-42.1`–`42.7`) | specified | The registry separates stable providers, experimental candidates, diagnostics, retired selectors, implementation state, and activation state. Existing domain specs own mode semantics. | Add an audit that compares runtime-mutating selectors with this registry and the environment-variable rules. |
| Exclusive encode-execution resolver (`R-BACK-42.13`) | specified / not implemented | The current runtime has separate Tape, partition, and segmentation controls and a serial identity fallback. The policy now defines those as implementation/migration surfaces rather than independently composable provider axes. | Implement one queue-immutable `serial-direct|long-session-direct|parallel-compact-soa` resolver, requested/resolved reporting, unknown-value fallback, and an exclusive mode matrix. Add the canonical environment selector only when the resolver exists. |
| Serial direct cursor (`R-BACK-42.14`, `R-BACK-42.18`) | target default specified / partial mechanisms | Immutable source leases, synchronous source facades, serial cursors, transactional replay state, and carrier-free Arena paths exist. Production currently uses a Replay offload worker followed by a distinct `CommandQueue::encodeThread_`, materializes final queue storage, and retains `DrawRunSubmission` compatibility surfaces. Queue startup currently creates encode, finish, and completion workers as one group. | Consume every admitted source family and encode Metal on the same Unix replay/encode worker, remove the downstream Ready/ChunkSlot encode handoff and dedicated encode thread, and decouple finish/completion startup and teardown from encode-thread existence. Prove exact next-state/command/completion equivalence, then promote it over the current serial identity fallback. |
| Long-session direct cursor (`R-BACK-42.15`, `R-BACK-42.18`) | experimental / partial | EncodeSession lifecycle, completion, progress, and source-continuation mechanics are implemented behind the default-off Tape lane. GT2 correctness passed, but CB/pass/tile locality increased and FPS did not improve. The present implementation still hands work to the separate queue encode thread. | Rebase the session on the same fused replay/encode cursor owner, retain only session-owned Metal/lifetime state, close ordered-control and cross-source action evidence, and pass locality plus end-to-end economy gates before promotion. |
| Explicit parallel compact SoA (`R-BACK-42.16`, `R-BACK-42.18`) | experimental / current parallel mechanism differs | Sealed-pass certificates, child binding isolation, source-qualified locators, Metal equality fixtures, and explicit parallel execution exist. Measured GT2 was producer-paced and performance-neutral; the current path is not the specified pass-local compact indexed SoA provider. | Add bounded pass-local count/dedup and indexed unique tables only after pre-eligibility acceptance. This is the sole provider allowed a Replay-to-encode-coordinator handoff and bounded child pool. Prove direct-serial equivalence and complete fallback conservation, and reopen promotion only when encode is a measured critical path. |
| Producer replay classification | implemented / target-topology coupling specified | Inline rollback and engine-default offload are both implemented and regression covered. The target direct providers require Unix offload because their Replay worker becomes the Metal encode owner; inline replay remains compatibility-only. | Bind provider resolution to this dependency without making the PE/game thread a Metal owner. A canonical positive typed selector may replace the boolean opt-out surface only if migration preserves `DXMT9_OFFLOAD_COMMIT_REPLAY`. |
| Submission and Present policies | partial | Mid-chunk, acquire, and boundary pure resolvers plus native matrices exist. Framebuffer-only drawable behavior is specified as D3D9-neutral. | Classify or retire `per-n-records`; add canonical single selectors for acquire/boundary only if legacy precedence and app overrides are preserved. Deferred boundary remains experimental. Add the missing framebuffer-only Lock/GetRenderTargetData conformance evidence routed through the D3D9 WSI gap. |
| Binding and tile providers | binding implemented; tile correctness-blocked | Stage 1/Stage 2/Stage 2b/resource-array are implemented. The tile candidate passes the full-screen single-draw fixture, but `dxmt9_tile_ffp_partial_rect_preserves_clear_readback` proves that the attachment-wide post-process fogs uncovered clear pixels under the diagnostic route. Non-diagnostic `tile-auto` therefore resolves to portable. | Keep Stage 1 and portable fallbacks. Tile promotion requires coverage/prior-colour composition plus partial, overlap, alpha-reject, and multi-draw GPU equality before any workload perf gate. Add requested/resolved startup reporting shared with the registry. |
| Experimental-candidate cleanup | open | Active rules identify candidate and diagnostic selectors; retired families are explicitly not honored. | Remove rejected candidates when no new workload justifies them, or promote them through an owning requirement. Do not preserve correctness-invalid probes as provider modes. |
| Opaque-depth LRU32 candidate economy | implemented / opt-in | The original-order fallback is default. Opt-in candidate construction now rejects production draws below 256 primitives before locality measurement, bounds the builder at 65,536 triangles / 256 frontier entries / deterministic linear selection work, and aborts the complete candidate without changing output when a bound is reached. Gate failures are attributed by primitive bucket; pre-gate and typed budget abort counters are included in the shutdown report. Diagnostic probes retain an explicit unbounded builder path. | Re-measure only after the pre-gate/budget shape is validated; promotion still requires workload benefit, exact visual equality, and locality conservation. |
