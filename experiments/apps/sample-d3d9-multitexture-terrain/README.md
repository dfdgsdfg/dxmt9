sample-d3d9-multitexture-terrain is a repo-local Direct3D 9 sample focused on terrain-style material composition:

- multiple texture samplers in one pixel shader
- blend-map based material mixing
- terrain-like lower-screen composition

It is intended as the second commercial-game proxy after `sample-d3d9-water-rt`, targeting
terrain/material issues that show up in outdoor DX9 scenes.
